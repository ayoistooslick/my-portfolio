# Ayodele Ayokunle David — Portfolio

Personal developer portfolio for **Ayodele Ayokunle David** (`ayoistooslick`), based in Warri, Delta State, Nigeria.

The site is built with the repository's existing Next.js App Router setup. It presents an introduction, experience and open-source contributions, skills, education and mentorship, selected projects, and contact links. PlainScript is featured as the flagship project. Renew is marked paused / experimental.

## Run locally

```bash
npm ci
npm run dev
```

Open `http://localhost:3000`. To produce a production build, run `npm run build`; to serve it locally, run `npm start`.
